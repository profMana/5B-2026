# 🚀 5B info - Web Application  

Raccolta di esercizi di **Applicazioni Web Client Server**. 
In questo repository sono raccolti gli esercizi di **Nodejs**, **MongoDB**, **Express** **Angular** **React**.

---

## 📂 Struttura del Repository

Il progetto è organizzato in cartelle tematiche, ordinate per tecnologia e flusso di lavoro:

```text
├── 01-Typescript/      # Sintassi Base di Typescript
├── 02-Node/            # Sviluppo lato server, moduli nativi, NPM e gestione file
├── 03-mongoDB/         # Database NoSQL, gestione collezioni, CRUD e query avanzate
├── 04-express/         # Creazione di API RESTful, middleware e gestione delle rotte
├── 05-angular/         # Framework frontend: componenti, servizi, moduli e routing
└── 06-react/           # Libreria frontend: componenti (funzionali/classe), Hooks e stato
```

---

## 🛠️ Tecnologie Utilizzate

*   **Node.js:** Runtime JavaScript lato server per creare applicazioni scalabili.
*   **MongoDB:** Database NoSQL orientato ai documenti per l'archiviazione flessibile dei dati.
*   **Express:** Framework minimalista per Node.js per lo sviluppo rapido di API e applicazioni web.
*   **Angular:** Framework strutturato di Google (TypeScript) per lo sviluppo di Single Page Application (SPA).
*   **React:** Libreria open-source di Meta per la creazione di interfacce utente dinamiche e componenti riutilizzabili.

---

## 📈 Obiettivi  

*   [ ] Comprendere l'architettura a componenti sia in ambiente Angular che React.
*   [ ] Progettare, testare e documentare API REST complete utilizzando Express.
*   [ ] Interrogare e gestire in modo efficiente un database non relazionale come MongoDB.
*   [ ] Collegare applicazioni frontend moderne con un backend Node.js (Full-Stack).
